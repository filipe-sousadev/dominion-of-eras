# Créditos

## Arquivos do jogo original utilizados
Nenhum. A pasta do projeto não tinha uma cópia instalada do jogo de referência — apenas um instalador
web, um script de instalação e capturas de tela da jogabilidade — então não havia modelos, texturas,
sons, músicas, fontes ou mapas para aproveitar.

## Do que este jogo é feito
- Todos os modelos 3D são montados em código a partir de formas simples (`scripts/meshes.gd`): arte original.
- Todos os ícones da interface são desenhados em código (`scripts/icons.gd`): arte original.
- Terreno, mar, bordas de território, névoa de guerra e neve são desenhados por shaders próprios
  (`scripts/game.gd`, `scripts/meshes.gd`).
- Interface, nomes ("Dominion of Eras", nomes de territórios e de rivais) e textos são originais.
- As capturas em `reference/` serviram apenas para estudar como o gênero se joga e como a tela é
  organizada; nada delas é copiado para dentro do jogo.
- Motor: Godot Engine 4.4.1 (licença MIT).
